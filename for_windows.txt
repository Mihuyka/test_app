1) Download msys2, VSCode
2) Open ucrt64.exe and write the following commands:
    pacman -Syu
    pacman -S --needed base-devel
    pacman -S --needed mingw-w64-ucrt-x86_64-toolchain
    pacman -S --needed mingw-w64-ucrt-x86_64-cmake
    pacman -S --needed mingw-w64-x86_64-gtkmm-4.0
3) Add the path of your ucrt64 bin folder to the Windows PATH environment variable by using the following steps:
    3.1) In the Windows search bar, type Settings to open your Windows Settings
    3.2) Search for Edit environment variables for your account
    3.3) In your User variables, select the Path variable and then select Edit
    3.4) Select New and add the MinGW-w64 destination folder you recorded during the installation process to the list. If you used the default settings above, then this will be the path: C:\msys64\ucrt64\bin
    3.5) Select OK, and then select OK again in the Environment Variables window to update the PATH environment variable. You have to reopen any console windows for the updated PATH environment variable to be available
4) Open VScode and download C/C++ Extension Pack, this extension pack includes:
    C/C++
    C/C++ Themes
    C/C++ DevTools
    CMake Tools
5) Build your project
